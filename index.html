부산국제록페스티벌

친구들끼리 볼 공연, 쉬는 시간, 돗자리 자리를 같이 기록하는 시간표예요. 기록은 우리 그룹 Firebase에만 저장돼요. 구글 계정만 있으면 무료로 10분이면 만들어요.

완성 화면 미리 보기

그룹에서 한 명만 하면 돼요. 나머지 친구들은 마지막에 나오는 링크만 받으면 끝이에요. 컴퓨터 크롬에서 하면 편하고, Firebase는 새 탭에서 열어서 이 화면은 그대로 두세요.

  1. Firebase 프로젝트 만들기 Firebase는 구글이 무료로 주는 저장 공간이에요. 우리 그룹 기록이 여기에 저장돼요.
    • Firebase 콘솔을 새 탭으로 열고 구글 계정으로 로그인
    • Firebase 프로젝트 만들기 (또는 프로젝트 추가, 시작하기) 클릭
    • 프로젝트 이름은 아무거나 영어로. 예: burock-ourteam → 약관 체크 → 계속
    • Gemini, Google 애널리틱스를 켤지 물어보면 전부 끄고 계속
    • "새 프로젝트가 준비되었습니다"가 나오면 계속
    💰 처음 만들면 Spark(무료) 요금제예요. 카드를 등록하지 않으면 돈이 나갈 수 없어요. 업그레이드, Blaze 버튼은 누르지 마세요.
  2. Firestore(저장소) 만들기
    • 프로젝트 화면 왼쪽 메뉴 데이터베이스 및 스토리지 클릭 (메뉴가 안 보이면 왼쪽 위 ☰)
    • 펼쳐진 메뉴에서 Firestore 클릭 (Realtime Database가 아니에요)
    • 데이터베이스 만들기 클릭 후 이렇게 고르기
      버전: Standard · ID: 그대로 (default) · 위치: asia-northeast3 (Seoul) · 규칙: 프로덕션 모드
    • 만들기 → "데이터베이스를 사용할 준비가 되었습니다"가 나오면 완료
  3. 보안 규칙 붙여 넣기 "누가 무엇을 저장할 수 있는지" 정하는 문장이에요. 이 앱용으로 준비돼 있어서 복사해서 붙여 넣기만 하면 돼요. 2026-10-07 0시가 지나면 자동으로 잠겨요.
    • Firebase 탭 Firestore 화면 위쪽 탭 중 규칙 클릭 (데이터 · 규칙 · 색인 …)
    • 글 상자 안을 클릭하고 Ctrl + A → Delete로 원래 내용을 전부 지우기
    • Ctrl + V로 붙여 넣기 → 오른쪽 위 게시 (확인 창이 뜨면 한 번 더 게시)
    맥은 Ctrl 대신 ⌘(Command)예요.
  4. 웹 앱 등록하고 설정 붙여 넣기
    • Firebase 왼쪽 위 ⚙ 톱니바퀴 → 프로젝트 설정
    • 일반 탭을 아래로 내리면 내 앱 → 동그란 아이콘 중 </>(웹) 클릭
    • 앱 닉네임 아무거나 (예: burock) → Firebase 호스팅도 설정은 체크 안 함 → 앱 등록
    • 나오는 코드에서 const firebaseConfig = {부터 };까지 드래그해서 복사 (조금 넓게 복사해도 괜찮아요)
    • 아래 상자에 붙여 넣고 연결 확인하고 링크 만들기
