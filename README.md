# 부산국제록페스티벌 친구 동선

2026 부산국제록페스티벌(10.2–10.4, 삼락생태공원) 공식 시간표 위에 **친구들이 볼 공연, 쉬는 시간, 돗자리 자리**를 같이 기록하는 웹앱이에요.

- 무대별 시간표 / 친구별 동선 / 무대 지도
- 로그인 없이 링크만 있으면 친구들이 같이 기록
- **2026-10-07 00:00(한국 시간)에 자동으로 닫혀요.** 저장소 읽기·쓰기가 막히고 종료 화면이 나와요.

이 저장소를 복사해서 **내 Firebase(저장소)와 내 GitHub Pages(사이트)** 로 쓰는 방법이에요. 전부 무료이고, 명령어 없이 브라우저에서만 하면 돼요. 15분 정도 걸려요.

---

## 1. Firebase에 저장소 만들기

1. https://console.firebase.google.com 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 돼요)
2. 왼쪽 메뉴 **데이터베이스 및 스토리지 → Firestore → 데이터베이스 만들기**
   - 버전: Standard / 위치: `asia-northeast3 (Seoul)` / **프로덕션 모드**
3. Firestore 화면 위쪽 **규칙** 탭 → 안에 있는 내용을 전부 지우고 이 저장소의 [`firestore.rules`](firestore.rules) 내용을 통째로 붙여 넣기 → **게시**
4. **설정(톱니바퀴) → 프로젝트 설정 → 일반 → 내 앱 → 웹(`</>`)** 으로 앱 등록 (호스팅 체크는 안 해도 돼요)
5. 화면에 나오는 `const firebaseConfig = { ... }` 안의 값을 복사해 두기

> 요금제는 기본값인 **Spark(무료)** 그대로 두세요. 카드 등록이 없으면 요금이 나오지 않아요. "업그레이드(Blaze)"는 누르지 마세요.

## 2. GitHub에 내 사이트 만들기

1. 이 저장소 오른쪽 위 **Use this template → Create a new repository**
   - 이름 예: `busan-rock` / **Public** 선택 → 만들기
2. 새로 생긴 내 저장소에서 `config.js` 클릭 → 연필(편집) 아이콘
3. 1-5에서 복사한 값으로 `YOUR_...` 부분을 바꾸고 **Commit changes**
4. **Settings → Pages**
   - Source: **Deploy from a branch** / Branch: **main**, 폴더 **/(root)** → Save
5. 1~2분 뒤 같은 화면 위쪽에 `https://내아이디.github.io/busan-rock/` 주소가 떠요

이 주소를 친구들 단톡방에 공유하면 끝이에요.

## 3. 쓰는 법

- 오른쪽 위 **인원 목록**에서 각자 이름을 추가하고 **내 이름**을 골라요.
- **시간표**에서 볼 공연 칸을 누르면 선택, 한 번 더 누르면 해제.
  - PC는 마우스를 올리면, 폰은 **꾹 누르면** 공연 정보와 고른 친구가 떠요.
- **+ 쉬는 시간**으로 밥·휴식 시간을 넣어요. 돗자리를 골라 두면 지도에 표시돼요.
- **지도**에서 **+ 돗자리**로 자리를 놓고, 끌어서 옮겨요.

## 알아 두기

- 링크를 아는 사람은 누구나 기록을 고칠 수 있어요. 링크는 친구들끼리만 공유하세요.
- `config.js`의 값은 공개돼도 괜찮아요. 실제 보호는 `firestore.rules`가 해요.
- 축제가 끝난 뒤 남은 데이터를 지우고 싶으면 Firebase 콘솔 → Firestore → `friends`, `spots` 컬렉션을 삭제하면 돼요. 프로젝트를 통째로 지워도 돼요.
- 시간표는 9월 17일 공개된 공식 타임테이블 기준이에요. 현장 변경이 있을 수 있어요.
