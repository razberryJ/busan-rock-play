## 따라 하기

먼저 **https://razberryj.github.io/busan-rock-play/** 를 열어 두세요. **"우리 그룹 만들기"** 화면이 나와요. 이 화면의 1~4번을 순서대로 하면 돼요. 아래는 그걸 더 자세히 풀어 쓴 거예요.

> Firebase 화면은 탭을 하나 더 열어서 하세요. "우리 그룹 만들기" 화면은 닫지 말고 그대로 두세요.

### 1. Firebase 프로젝트 만들기

Firebase는 구글이 무료로 제공하는 **저장 공간**이에요. 우리 그룹 기록이 여기에 저장돼요.

1. 새 탭에서 **https://console.firebase.google.com** 을 열고 구글 계정으로 로그인해요.
2. **"Firebase 프로젝트 만들기"** (또는 **"프로젝트 추가"**, **"시작하기"**) 를 눌러요.
3. **프로젝트 이름**을 아무거나 적어요. 예: `burock-우리팀` → 영어로 `burock-ourteam`
   - 약관 동의가 나오면 체크하고 **계속**
4. **Gemini**, **Google 애널리틱스** 같은 걸 켤지 물어보면 전부 **끄거나 "아니요"** 를 고르고 **계속**을 눌러요.
5. 잠깐 기다리면 **"새 프로젝트가 준비되었습니다"** 가 나와요 → **계속**

> 💰 **요금 걱정은 안 해도 돼요.** 처음 만들면 **Spark(무료)** 요금제예요. 카드를 등록하지 않으면 돈이 나갈 수가 없어요.
> 화면에 **"업그레이드"** 나 **"Blaze"** 버튼이 보여도 **누르지 마세요.**

### 2. Firestore(저장소) 만들기

1. 프로젝트 화면 왼쪽 메뉴에서 **"데이터베이스 및 스토리지"** 를 눌러요. (메뉴가 안 보이면 왼쪽 위 ☰ 를 눌러요)
2. 펼쳐진 메뉴에서 **"Firestore"** 를 눌러요. (Realtime Database 말고 **Firestore**예요)
3. **"데이터베이스 만들기"** 를 눌러요.
4. 나오는 질문에 이렇게 골라요.
   - 버전(Edition)을 물어보면: **Standard**
   - 데이터베이스 ID: 그대로 `(default)`
   - 위치: **`asia-northeast3 (Seoul)`**
   - 보안 규칙: **프로덕션 모드**
5. **만들기** → 잠깐 기다리면 **"데이터베이스를 사용할 준비가 되었습니다"** 가 나와요.

### 3. 보안 규칙 붙여 넣기

규칙은 "누가 무엇을 저장할 수 있는지" 정하는 문장이에요. 이 앱에 맞는 규칙이 이미 준비돼 있어서 **복사해서 붙여 넣기만** 하면 돼요.

1. **"우리 그룹 만들기"** 화면으로 돌아가서 3번의 **[규칙 복사]** 를 눌러요.
2. Firebase 탭으로 가서, Firestore 화면 위쪽 탭 중 **"규칙"** 을 눌러요. (데이터 · **규칙** · 색인 …)
3. 글 상자 안을 클릭하고 **Ctrl + A** (전체 선택) → **Delete** 로 원래 있던 내용을 **전부 지워요.**
4. **Ctrl + V** 로 붙여 넣어요.
5. 오른쪽 위 **"게시"** 를 눌러요. 확인 창이 뜨면 한 번 더 **게시**.

> 맥이라면 Ctrl 대신 **⌘(Command)** 예요.

### 4. 웹 앱 등록하고 설정 붙여 넣기

1. Firebase 왼쪽 위 **⚙ 톱니바퀴(설정)** → **"프로젝트 설정"** 을 눌러요.
2. **일반** 탭을 아래로 쭉 내리면 **"내 앱"** 이 있어요. **"프로젝트에 앱이 없습니다"** 아래 동그란 아이콘 중 **`</>`** (웹) 을 눌러요.
3. **앱 닉네임**에 아무거나 적어요. 예: `burock`
   - **"Firebase 호스팅도 설정"** 은 체크하지 **마세요.**
   - **앱 등록** 을 눌러요.
4. 이런 코드가 나와요.

   ```js
   const firebaseConfig = {
     apiKey: "AIza....",
     authDomain: "burock-ourteam.firebaseapp.com",
     projectId: "burock-ourteam",
     ...
   };
   ```

   `const firebaseConfig = {` 부터 `};` 까지 **마우스로 드래그해서 복사**해요. (조금 더 넓게 복사해도 괜찮아요)
5. **"우리 그룹 만들기"** 화면으로 돌아가서 4번 글 상자에 **붙여 넣고**, **[연결 확인하고 링크 만들기]** 를 눌러요.
6. **"연결됐어요!"** 가 나오고 아래에 **우리 그룹 링크**가 생기면 성공이에요 🎉

### 5. 친구들한테 공유하기

- **[링크 복사]** 를 눌러서 단톡방에 붙여 넣으면 끝이에요.
- 이 링크가 **우리 그룹 전용 주소**예요. 잃어버리지 않게 단톡방 공지 같은 데 올려 두세요.
  (잃어버려도 "우리 그룹 만들기" 화면 4번에 같은 설정을 다시 붙여 넣으면 똑같은 링크가 다시 나와요)

## 연결이 안 될 때

"우리 그룹 만들기" 화면에 나오는 빨간 글씨별로 이렇게 해 보세요.

| 화면에 나온 말 | 이렇게 해 보세요 |
|---|---|
| apiKey와 projectId를 찾지 못했어요 | 4번에서 `const firebaseConfig = {` 부터 `};` 까지 **통째로** 다시 복사해서 붙여 넣기 |
| 규칙이 아직 안 바뀌었어요 | 3번 규칙을 붙여 넣고 **게시**까지 눌렀는지 확인. 게시하고 1분쯤 뒤에 다시 누르기 |
| Firestore가 아직 없어요 | 2번 **데이터베이스 만들기**를 먼저 하기. **Realtime Database가 아니라 Firestore**인지 확인 |
| 응답이 없어요 | 인터넷 연결 확인 → 2번 Firestore를 만들었는지 확인 → 잠시 뒤 다시 누르기 |
| 설정값이 맞지 않아요 | 다른 프로젝트 설정을 복사했을 수 있어요. 방금 만든 프로젝트의 설정인지 확인하고 다시 복사 |

## 쓰는 법 (친구들한테도 알려 주세요)

1. 링크를 열고 오른쪽 위 **인원 목록** 에서 **내 이름을 추가**하고, 내 이름을 눌러 **"나"로 선택**해요.
2. **시간표** 에서 볼 공연 칸을 누르면 선택, 한 번 더 누르면 해제예요.
   - 컴퓨터에서는 공연 칸에 **마우스를 올리면**, 폰에서는 **꾹 누르면** 공연 정보와 고른 친구가 떠요.
3. **친구 동선** 에서 친구마다 하루 일정이 한 줄로 보여요.
4. **+ 쉬는 시간** 으로 밥·휴식 시간을 넣어요. 돗자리를 골라 두면 지도에서 그 자리에 표시돼요.
5. **지도** 에서 **+ 돗자리** 로 우리 자리를 찍고, **끌어서** 옮겨요. 시각 슬라이더를 움직이면 그 시간에 누가 어느 무대에 있는지 보여요.
